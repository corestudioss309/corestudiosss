# Core Studios

Core Studios is a React, TypeScript, and Vite website.

## Development

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm test
npm run build
```

## Database migrations

Set `DB_MIGRATION_URL` to the PostgreSQL connection string before running Drizzle migrations.
